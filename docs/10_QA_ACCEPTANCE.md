# テスト計画と受け入れ基準

## 2026-11-06 実行結果サマリ
- 合格: unit 73件（計算・UNKNOWN・クーポン・為替・順位・リダイレクト・冪等・CSV・取り込み・生成検証）、E2E 30件（desktop/mobile 375px、smoke 22 + axe 8）、lint/typecheck/build。
- 合格: Preview noindex、`/go` のallowlist、サンプル価格の本番非表示、法的表示ページの存在。
- BLOCKED（資格情報・承認が必要）: 外部Previewデプロイ、GA4/GSC実データ検証、ASP成果の実連携、Buffer公式API、本番DNS切替、旧サイトの実バックアップ。
- NOT RUN: Lighthouse実測（CI環境のため）、実端末スクリーンリーダー、負荷試験。

## 原則
単体/統合/E2E/セキュリティ/SEO/視覚/運用テストを各PRで実行。外部API・サービスに資格情報がない場合は、実データとモックを明確に分ける。テスト未実行を成功と記載しない。

## Unitテスト
- [ ] 総額の税込/税抜/送料/手数料/税・関税の条件に一致する計算。
- [ ] 未知項目はNULL/UNKNOWNとして扱い、0円/最安ランキングに紛れ込まない。
- [ ] クーポンの閾値・上限・対象・有効期限、ポイント利用の二重計上を防ぐ。
- [ ] 為替換算（精度/rounding/日付）と通貨ペアの境界、請求通貨違い。
- [ ] ホテル条件（日付/人数/宿泊日数/子ども条件/キャンセル/朝食/現地税）が揃わない場合は比較不可。
- [ ] 公開不可の古いオファー・提携未承認リンク・誤った媒体を排除。
- [ ] 外部リンクリダイレクト（/go/id）が未登録のホスト/任意URLを拒否。
- [ ] 投稿の再試行と成果取り込みが冪等で重複しない。

## Integrationテスト
- [ ] 公式API/許諾フィードのスキーマ変更・タイムアウト・429・5xx・期限切れで安全停止。
- [ ] PostgreSQLマイグレーション・障害時ロールバック。
- [ ] LLMのフォーマット破損・架空の価格が検出され、下書きで停止する。
- [ ] Buffer未接続/開示不足/予約枠上限/資格情報失効時にPR投稿しない。
- [ ] ASPの保留/承認/却下/返金/入金で確定額と見込額を分離。
- [ ] クリック計測の送信失敗で外部遷移を阻害しない。

## UI / E2E / A11y
- [ ] モバイル375px/タブレット/PCで比較表とCTAが閲覧可能。
- [ ] キーボード・フォーカス・ラベル・コントラストの基本検証。
- [ ] 料金/条件/取得日/出典/計算式/広告表記が各比較ページで見える。
- [ ] サンプル価格を実際の価格と誤認させない。
- [ ] 404/500/空データ/リンク切れ/画像なしの表示を用意。
- [ ] E2E: 訪問→条件編集→計算再表示→承認済み提携先への遷移。

## SEO
- [ ] canonical/sitemap/robots/OG/JSON-LDが実ページと矛盾しない。
- [ ] Previewはnoindex、本番の必要ページのみindex。
- [ ] 新旧URLのリダイレクト表、内部リンク、孤立ページのチェック。
- [ ] 引用元・最終確認日を追跡できる。
- [ ] LighthouseとCore Web Vitalsの定期測定。

## 本番リリースの承認ゲート
- [ ] 旧サイト8 URLのバックアップと復元演習・現在のDNS設定の控え。
- [ ] ASP承認/掲載媒体/広告開示のレビュー。
- [ ] 契約条件・費用見積・権限確認。
- [ ] 破壊的変更の差分とロールバック計画を提示。
- [ ] 本人が本番DNS/切替と公開投稿を明示的に承認。
- [ ] 本番直後の主要URL/TLS/記事/広告リンク/計測のスモークテスト。

## 合格基準
重大/高リスクの失敗0件。検証不能はPASSでなくBLOCKED/NOT RUNと報告。収益30万円はテスト合格基準ではなく長期の事業KPI。
