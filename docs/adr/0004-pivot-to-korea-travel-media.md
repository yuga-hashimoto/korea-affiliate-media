# ADR-0004: 「総額比較エンジン」廃止と韓国旅行メディアへの転換

- 日付: 2026-11-06
- 状態: 採用・本番反映済み（2026-11-07）
- 関連: `docs/00_PROJECT_CHARTER.md`, `docs/01_PRD.md`, ADR-0001/0002/0003

## 背景
- 既存ドメイン `sougakuhikaku.com` の「総額比較」サイトはユーザー自身が制作したが、機能していない。
- 事業の目的は「韓国旅行メディア」として育てることにある。
- 総額比較エンジン（Offer/Coupon/為替換算/順位付け/サンプル価格/`/go`/比較API）はプロダクトの主役ではない。

## 判断
1. **比較エンジンを廃止**する。比較UI・サンプルオファー・`/go`・`/api/v1/comparisons`・フィード取り込み・為替更新を削除した。
2. **韓国旅行メディアへ転換**する。カテゴリは ソウル / 釜山 / 済州島 / グルメ / カフェ / 買い物 / 交通 / 宿泊 / 旅の準備 / 韓国コスメ / 韓国ファッション。
3. **ブランド名は暫定「韓国旅行ノート」**。ドメインは `sougakuhikaku.com` を継続する（DNS変更なし）。正式名称は公開前に決定できるよう `SITE` 定数1箇所に集約した。
4. **既存のウォーターサーバー記事2件は公開時に削除してよい**（ユーザー承認済み）。ただし削除の実行は本番切替時に行い、バックアップとGSC確認を前提とする。
5. 収益化は旅行・宿泊・体験・コスメのアフィリエイトを想定する。成果リンクはASP承認後、`AffiliateProgram` の管理下でのみ扱う。

## 廃止したもの
- `Offer` / `Coupon` / `FxRate` のドメイン型、総額計算・比較・為替換算ライブラリ
- 比較ページのUI、サンプル価格、`SAMPLE` バナー
- `/go/[id]` リダイレクトとクリック計測、`/api/v1/comparisons`
- フィード取り込みコネクター、為替レート更新ジョブ

## 残したもの
- 記事・出典（`SourceEvidence`）・編集状態、AI下書きと品質ゲート、X投稿の承認・配信
- 提携プログラム（`AffiliateProgram`）とASP成果CSVの集計
- SEO（sitemap/robots/canonical/OGP/JSON-LD）、アクセシビリティ、CI/E2E

## 実施（2026-11-07）
- Cloudflare Pages の既存プロジェクト `sougakuhikaku` に静的書き出しを配信し、カスタムドメイン `sougakuhikaku.com` を再利用した（ADR-0005）。
- 旧サイトのコンテンツは上書きされ、旧ウォーターサーバー記事は404になった（ユーザー承認済み）。
- 正式ブランド名は引き続き暫定（韓国旅行ノート）。

## 影響
- 旧URLのうち `/korea/travel/esim` は通信ガイド記事へ、`/korea/travel/airport-transport` は空港アクセス記事へ308転送。
- `/methodology` は編集方針へ308転送。比較手法の記述は削除した。
- 収益KPIは「比較経由の成果」ではなく、旅行記事からのアフィリエイト成果として再設計する必要がある（`docs/09_KPI_MODEL.md` は要更新）。

## ロールバック
- 比較エンジンは Git 履歴（`5d49c9e` など）から復元可能。
- ブランド名は `SITE` 定数の変更のみで差し替えられる。
