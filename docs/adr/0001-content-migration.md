# ADR-0001: 既存サイト（ウォーターサーバー記事）との共存・移行方針

- 日付: 2026-11-06
- 状態: 提案（本番切替は未承認）
- 関連: `docs/06_DOMAIN_MIGRATION.md`, P0-03

## 論点
`sougakuhikaku.com` には既存の比較サイト（サイトマップ8 URL、ウォーターサーバー記事2件）が公開されている。
新メディア（韓国旅行・韓国コスメ）を同一ドメインで始めるにあたり、旧URLをどう扱うか。

## 観測（2026-11-06・読み取りのみ）
- `/`, `/articles/`, `/methodology/`, `/editorial-policy/`, `/about/`, `/privacy/`
- `/articles/premium-water-amadana-53b10b-24monthja-jp/`
- `/articles/premium-water-famfit2-24monthja-jp/`
- robots.txt は `/go/` を Disallow、Search Console 検証メタタグあり（所有アカウントは未確認）。
- 検索流入・被リンク・GSC実データは**未取得**。したがって「流入がない」とは判断しない。

## 選択肢
- **A. アーカイブ + 301**: 旧記事を `/archive/` に移し、旧URLから301。SEO評価の引き継ぎが可能。ただし内容の意味的関連が薄いため、トップへの一律転送は行わない。
- **B. 410**: コンテンツ廃止を明示。検索流入がある場合の損失が大きい。
- **C. 段階的共存**: 旧URLをそのまま残し、新サイトを別プレビューで検証。切替時に新トップ/カテゴリを追加し、旧記事は保全したまま個別に判断する。

## 判断
**当面は C（段階的共存）**。理由:
1. GSC/被リンクの実データが未取得で、301/410の影響を定量評価できない。
2. 旧記事は「総額比較」というブランドと矛盾せず、即時削除の便益がない。
3. プレビュー検証中に本番コンテンツへ触れる必要がない。

本番切替時の個別方針（旧記事の維持・アーカイブ・301）は、GSCエクスポートと被リンク確認後に決定し、ユーザー承認を得る。

## 影響・コスト
- 影響: 切替後も旧記事のメンテナンス対象が残る。
- コスト: 追加のホスティング費用は想定しない（同一Next.jsアプリ内で配信する場合は実装工数のみ）。
- ロールバック: 旧サイトのバックアップ（HTML・画像・DNS設定）から復元。切替前のDNSレコードを控える。

## 未実施（ブロッカー）
- 旧サイトの実バックアップ（ホスティング/デプロイ元が不明）
- GSC/GA4の実データ取得（アカウント権限が必要）
- Cloudflare DNSの読み取り・変更権限の確認
- 本番DNS切替（明示承認が必要）
