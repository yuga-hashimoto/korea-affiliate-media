# プロジェクト憲章・基本方針

## 事業
- 名前: 総額比較（仮称）。日本語で「韓国旅行・韓国コスメのお得な総額比較」を訴求。
- ドメイン: `https://sougakuhikaku.com/`（ユーザー所有との申告）。
- サービス: 顧客が実際に払う総額を比較して予約/購入の判断を支援するサイト。
- 読者: 韓国好き日本人（初めての渡韓、年数回の旅行、韓国コスメ購入者、韓国ファッション購入者）。
- 集客: Google/Bing検索、X `@bts_95_y`、SNS紹介。特定芸能グループに依存しない。
- 収益: 審査承認されたアフィリエイト（旅行・現地体験・eSIM・韓国コスメ・ファッション）。
- 長期目標: 月額**30万円の確定報酬**（収益の予測や保証ではない）。
- 主要優先順位: 信頼性 > 安全性/規約順守 > 検索者の課題解決 > 計測可能な成約 > 自動化量。

## 価値仮説
旅行: 「ソウル滞在費の全体像」「ホテルにかかる税・朝食・移動費」「交通費込み」「韓国eSIMとWi-Fi」「現地通貨換算」。
コスメ: 「商品価格だけでなく送料・割引・税を含む実支払額」「販売サイト別の条件の違い」「有効期限と確認時刻」。
ファッション: 「サイズ・送料・返品条件・為替を揃えた比較」。最初は収益実績を見て拡大。

## MVPで扱わない
- 特定ファンダム・芸能IPに特化したサービス
- 実在しない口コミ/レビュー
- 取得権限のない店舗情報の大量スクレイピング
- 航空便やホテルの架空のリアルタイム在庫
- 自動DM・自動リプライ・フォロー/いいねの自動操作
- 個人情報を集める会員機能・決済機能

## ゴール判定
1. ブラウザで閲覧できるプレビューサイトと、検証可能な比較式。
2. 有効な一次情報と引用元、取得時刻・条件・UNKNOWN表示。
3. 法定表示・広告開示・プライバシーのベース整備。
4. 計測の契約/データ構造と、必要に応じたASPインポート。
5. X用のレビュー可能な投稿案生成とBuffer連携設計。
6. 本番ドメイン移行の保全・公開承認手順とロールバック。
