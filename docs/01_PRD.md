# PRD — 韓国旅行・韓国コスメ総額比較

## ユーザー課題 / Jobs to be done
- 旅行: 「旅行日程・人数・荷物で金額が違う。比較サイトの表示価格と実払額がズレるので、明細を見ながら選びたい」
- 韓国コスメ: 「楽天/Qoo10/韓国系通販で送料・クーポン・関税・為替が違い、最終支払額が分かりにくい」
- 新規: 「韓国旅行の準備を一覧化し、予約すべきものを漏れなく把握したい」
- 検索ユーザー: 「比較条件と根拠を理解し、自分に合う予約先/購入先を選びたい」

## 情報設計
- `/`: 価値訴求、用途別クイック比較、人気の記事、更新日、広告明示
- `/korea/travel/`: 旅行予算、ホテル比較、eSIM/交通/体験の比較
- `/korea/travel/hotels/`: 宿泊エリア別、日付/人数/部屋/税/キャンセルでフィルタ（ライブ在庫未提供時は参考条件として表示）
- `/korea/travel/esim/`: 容量/日数/対応端末/総額
- `/korea/travel/transport/`: 仁川空港からの交通手段など
- `/korea/beauty/`: コスメカテゴリ、送料込み価格比較
- `/korea/fashion/`: 第2フェーズのファッション比較
- `/articles/[slug]/`: 検索意図に直結する編集記事
- `/methodology/`: 比較式と評価基準、条件・データ更新方針
- `/editorial-policy/`, `/about/`, `/privacy/`, `/disclosure/`, `/contact/`
- `/go/[id]`: 外部クリック計測（同意/プライバシー対応・オープンリダイレクト防止・検索index除外）

## ユースケース（初期）
U1: 条件が同じ3件のeSIMプランを日数・GB・円換算で比較。最低価格は税/送料/為替のUNKNOWNがあれば確定最安と言わない。
U2: 韓国コスメ商品ページで複数ストアの単価・送料・条件付きクーポン・返品可否・更新日時を比較。
U3: 韓国滞在エリア比較で徒歩/鉄道移動、ホテル相場の出典、変更可能な旅程条件を提示（旅行費用の目安とライブ価格を混同しない）。
U4: 記事から提携先への外部リンクへ移動。PR/広告表記が同一画面で理解できる。
U5: 編集者が情報ソース・発効期間・通貨・条件・例外を更新すると、依存する比較表示が再検証される。
U6: SNS原稿生成後、許可したものだけ公開。公開後に成果計測。

## 非機能要件
- モバイルファースト、レスポンシブ、日本語、日付/金額/通貨の一貫した表示、キーボード操作とスクリーンリーダー。
- SEO: canonical、OGP、sitemap、パンくず、ページごとに固有の検索意図。スパムな大量生成は禁止。
- パフォーマンス: 初期目標 Core Web Vitals の良好評価、LCP <=2.5s, CLS <=0.1, INP <=200ms（実ユーザー/計測条件を明記）。
- セキュリティ: 環境変数で秘密情報、RBAC最小権限、オープンリダイレクト禁止、CSP/HTTPヘッダー、rate limiting、入力検証。
- 信頼: 数値は出典、確認日時、適用条件、通貨換算レートと時刻が追える。古いものは期限切れ表示。
- 可用性: 公開ルートはソース取得が落ちてもキャッシュで表示し、情報の鮮度を明示。外部リンクは破損時非表示。
- i18n: MVP日本語のみ。英語のUI必須にしない。

## コンテンツ公開の受入基準
1. 人手または検証済みソースによる一次情報の根拠がある。
2. 比較条件が明示されている。
3. 段階的な費用内訳と税込/送料/手数料/クーポン/為替を説明している。
4. 広告を含む場合、広告表記と成果リンクの説明。
5. 更新日時と責任ある編集手順。
6. 架空のレビュー/試用・未検証の最安/割引を含まない。
