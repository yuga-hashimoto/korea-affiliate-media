# 法令・プラットフォーム規約・セキュリティ

本書は開発のチェックリストであり法的助言ではない。媒体・商品・対象市場ごとの最新版を確認する。

## 広告表示
- 消費者庁のステルスマーケティング規制に沿い、「広告」「PR」等が利用者に明瞭となる位置に表示する。記事や投稿の商用性を隠さない。
- 消費者庁: https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing
- Xはアフィリエイトリンクや報酬対象クーポンをPaid Partnership対象とし、投稿時の専用開示設定を要求。Bufferでその設定を担保できない場合、PR自動投稿は禁止する。
- X有料パートナーシップ: https://help.x.com/ja/rules-and-policies/paid-partnerships-policy
- X自動化: https://help.x.com/en/rules-and-policies/x-automation
- サイト内広告リンクは rel="sponsored"。Google: https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links?hl=ja

## SEOと生成AI
検索順位操作を主目的とする大量の低価値ページ生成は禁止。LLM生成でも一次情報の確認、計算の透明性と独自価値を必須にする。
Google: https://developers.google.com/search/docs/essentials/spam-policies?hl=ja

## 著作権・商標
- ロゴ/商品写真/芸能人の写真や動画は許諾された素材・公式埋め込み等、利用条件内で扱う。
- 体験していないサービスの「実際に使った」レビューや捏造クチコミを記載しない。
- 「公式」「認定」「最安値」「No.1」等は裏付けのない場合表示禁止。比較対象範囲を必ず明示。

## 美容・旅行・費用
- 医療/美容効能の誇張や、薬機法・景品表示法に触れる表現を避ける。
- 送料・輸入税・関税・為替は条件により変化する。適用法令の最新情報を官公庁/税関の一次情報で確認し、税率等を決め打ちしない。
- 旅行日程/空室/料金の変動、キャンセル・返金条件、現地徴収税/為替条件を明示。不明なら断定しない。

## セキュリティと個人情報
- Analytics/タグ/Cookieはポリシーに明記、対象法令・契約に応じて同意/オプトアウト実装。
- クリック計測でメール/電話等を要求しない。IPの永続保存を避ける。
- 問い合わせにrate limit、ボット対策、保存期間/送信先制限。
- キー/トークン/広告主パラメータを公開Git/CIログ/外部AI入力へ漏らさない。
- インシデント時は公開停止、鍵停止/ローテーション、影響確認/必要な通知を優先。

## 比較の公平性
- 広告案件と編集上のおすすめを区別し、スポンサー料だけでランキングを変えない。
- 取得不能な料金はUNKNOWNとし、0円補完・無根拠な最安表記をしない。
- 古いセール情報は自動停止。特商法表示の要件は運営形態に応じ公開前に確認する。
