# コンテンツ / SEO / X集客計画

## ブランド
- ドメインと一致する「総額比較」を活かし、韓国の総支払額比較で差別化。
- タイトル候補: 「総額比較｜韓国旅行・韓国コスメの費用をわかりやすく比較」
- 一次情報・計算式・比較前提・更新日を透明に。現地未訪問/未購入の場合は体験を装わない。
- 記事に広告リンクを含む場合、冒頭とリンク近辺に明確な広告開示。
- 既存のウォーターサーバー比較記事は移行方針を決めるまで変更・削除しない。

## 記事テンプレート
1. 読者の疑問と結論の範囲
2. 比較条件（利用日、人数、製品容量、販売通貨など）
3. 比較表（税/送料/手数料を分けた総額）
4. 条件別おすすめ（広告料と独立した基準）
5. コスト計算と根拠・公式URL
6. 対象外/UNKNOWN/価格変動/更新日時
7. よくある質問・関連記事・広告表示
8. 編集履歴・修正受付窓口

## X戦略
- チャンネル `@bts_95_y` はBuffer連携済みとの確認がある。ただし過去のテーマと新テーマに差があるため、移行初期は反応を確認。
- 目安: 1日2投稿（通常情報/比較の紹介）→毎週評価、初期は宣伝過多にしない。
- 月配分の初期仮説: 40%有益情報、40%記事導線、20%PR。数値はテスト条件であり規則ではない。
- 投稿ごとに UTM（source=x, medium=social, campaign, content）を記録し、広告提携先でパラメータ追加が許可されている場合のみ利用。
- 週1回のトピックテスト: 韓国旅行の困りごと/交通/ホテルvsコスメ送料・割引。エンゲージメントより確定報酬/訪問を重視。
- 投稿文は独自性、情報価値、必要な開示を満たす。自動フォロー、自動DM、自動返信なし。

## 検証と更新
- Search Consoleで表示/クリック/クエリ/インデックス状況、GA4で入口/滞在/外部クリック、ASPで承認実績を紐付け。
- SEOの運用は「大量AI記事」より正確な比較条件、更新、問い合わせ対応、透明性に投資。
- スキーママークアップはページの実際の内容と一致。FAQリッチリザルトなど表示を保証しない。
